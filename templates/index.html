Ley de Enfriamiento de Newton

1. Ecuación Diferencial Ordinaria

dT / dt = -k · (T - Tₘ)
dT / dt = -0.08251 · (T - 1.0)

Tasa instantánea de transferencia de calor entre el lote de leche y el fluido refrigerante.

2. Cálculo de la Constante de Decaimiento k

k = -(1 / t) · ln( [T(t) - Tₘ] / [T₀ - Tₘ] )
k = -(1 / 5) · ln( [48.0 - 1.0] / [72.0 - 1.0] ) = 0.08251 min⁻¹

Coeficiente determinado dinámicamente a partir de la lectura en t = 5 min.

3. Proyección de Tiempo a Consigna (4°C)

t_final = -(1 / k) · ln( [T_obj - Tₘ] / [T₀ - Tₘ] )
t_final = -(1 / 0.08251) · ln( [4.0 - 1.0] / [72.0 - 1.0] ) = 38.34 min

Tiempo requerido para alcanzar la temperatura segura de almacenamiento.

4. Aproximación Numérica Runge-Kutta (RK4)

Tₙ₊₁ = Tₙ + (h / 6)·(k₁ + 2k₂ + 2k₃ + k₄)
Paso h = 1.0 min | Error medio absoluto: 0.000012 °C

Resolución numérica empleada ante variaciones en el medio refrigerante o activación de equipos auxiliares.
