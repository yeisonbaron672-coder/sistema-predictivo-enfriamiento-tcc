Modelo Matemático Aplicado en Tiempo Real (Ley de Enfriamiento de Newton)

Sustitución Dinámica

1. Ecuación Diferencial Ordinaria (EDO)

dT / dt = -k · (T - Tₘ)
dT / dt = -0.08251 · (T - 1.0)

Modela la tasa instantánea de enfriamiento de la leche dentro del tanque en función de la diferencia térmica con el refrigerante.

2. Despeje Dinámico de la Constante k

k = -(1 / t) · ln( [T(t) - Tₘ] / [T₀ - Tₘ] )
k = -(1 / 5) · ln( [48.0 - 1.0] / [72.0 - 1.0] ) = 0.08251 min⁻¹

A partir de la lectura del termopar en t = 5 min, el software obtiene la eficiencia térmica real del compresor.

3. Predicción del Tiempo para T(t) = 4°C

t_final = -(1 / k) · ln( [T_meta - Tₘ] / [T₀ - Tₘ] )
t_final = -(1 / 0.08251) · ln( [4.0 - 1.0] / [72.0 - 1.0] ) = 38.34 min

Permite conocer a los 5 minutos si el lote cumplirá el estándar de 45 minutos o si requiere acción correctiva inmediata.

4. Esquema Numérico Runge-Kutta 4to Orden (RK4)

Tₙ₊₁ = Tₙ + (h / 6)·(k₁ + 2k₂ + 2k₃ + k₄)
Paso h = 1.0 min | Error medio absoluto: 0.000012 °C

Resuelve la EDO de forma robusta cuando existen fluctuaciones en la temperatura ambiente o se activa la refrigeración auxiliar.
